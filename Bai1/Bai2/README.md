# Bài 2 — Ứng dụng quản lý công việc bằng Vue

## Chạy ứng dụng

Mở terminal tại thư mục `C:\Project\Bai2` (thư mục có `package.json`) và chạy:

```bash
npm run dev
```

Ứng dụng Vue nằm trong thư mục `Bai2/`. Component cha quản lý công việc và trạng thái bằng `watch`; component con nhận `props` và phát sự kiện `add-task`.
