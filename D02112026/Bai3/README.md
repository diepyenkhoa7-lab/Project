# Bài 3: Quản lý sản phẩm trà sữa

Vue 3 app dùng Pinia quản lý danh sách và Vuex quản lý trạng thái hộp thoại thêm/sửa.

## Chạy ứng dụng

```sh
npm install
npm run dev
```

## Chức năng

- Thêm, sửa và xóa sản phẩm.
- Phân trang 3 sản phẩm mỗi trang.
- Ảnh dùng URL hoặc file đặt trong `public/images`.
